# 日记版补丁：史料附页配图 + 翻页转场

## 为什么之前看不到

仓库里跑的是**日记版**（`index.html` + `styles.css` + `diary.css`），它是从早期版本分叉出去的，因此：

- `game.js` 的 `renderSourceCard()` 只写文字，`HISTORY_CARDS` 没有 `img` 字段；`index.html` 的 `#sourceCard` 里也没有图片容器；
- 仓库里没有 `assets/` 目录（`assets/history/yudu-bridge.jpg` 访问 404）；
- `nextQuestion()` 里没有转场逻辑——日记版比带转场的版本更早。

所以不是"图挂了"或"动画失效"，是这个分支压根没这两段代码。本补丁用**两个独立脚本**补上，`game.js` 一行都不用改。

## 接入步骤

1. 把 `assets/` 整个文件夹复制到仓库根目录（和 `index.html` 同级）。
2. 把 `art.js`、`transition.js` 放到仓库根目录。
3. 在 `index.html` 末尾，`<script src="game.js"></script>` 后面各加一行：

   ```html
   <script src="game.js"></script>
   <script src="art.js"></script>
   <script src="transition.js"></script>
   </body>
   ```

改完刷新即可，`game.js` 不用动。

## 两个脚本各做什么

**`art.js`** — 史料附页配图
监听 `#sourceCard` 的显示与 `#sourceCardKicker` 的文字（形如「史料附页 · 第 07 张 / 共 12 张」），据此换图，在附页顶部插入一张"贴在纸上的照片"（米色相框 + 胶带 + 做旧滤镜）。图片缺失时整块自动收起，不会出现破图。

**`transition.js`** — 翻页转场
监听 `#hudStationNo`（第几页）的变化。从第 N 页翻到第 N+1 页时，整屏出现下一页的照片：暗色底 + 米色相框照片 + 页码 + 标题 + 日期，停留约 1.15 秒后淡出，露出已经渲染好的题目。

- 每局第一页不播（开局直接进第一题），重开一局也不会误播；
- 转场期间点屏幕任意处、或按 `Esc` / `Enter` / 空格，立即跳过；
- 转场期间屏蔽其它按键，避免误触答题；
- 系统开启"减少动态效果"时自动去掉动画。

## 可选：路线图底图

日记版左侧路线图是手绘 SVG 风格，默认**不**铺照片底图。若想加，在 `diary.css` 末尾追加：

```css
body.diary .map-frame{
  background:
    linear-gradient(180deg,rgba(241,227,200,.62),rgba(233,216,184,.72)),
    #efe0c2 url("assets/route-map-crop.jpg") 50% 46%/cover no-repeat;
  border-radius:4px;
}
```
