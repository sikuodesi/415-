# 一个红军战士的日记

> 一本纸张发黄的红军日记，十二页，二万五千里。
> 雨水打湿了字，请你替他把模糊的地方一处一处补上。

这是一个以红军长征为主线的单页互动叙事游戏。纯前端实现，无构建步骤、无第三方依赖，克隆后双击 `index.html` 即可运行。

## 玩法

- **第一页是路线图**：从于都到会宁，十二个地名就是十二页日记。
- **每一页是一篇日记**：以一位普通红军战士的第一人称写成，参考纪实文学与长征史料。
- **补字**：每页都有一处被雨水洇开、字迹模糊。下方四张字条里只有一张能补得通，点字条或按 `1`—`4` 把字补进空白。
- **倒计时**：轻装 30 秒 / 标准 25 秒 / 铁血 19 秒；第 3、6、9、12 页为“难页”，时限更紧、军功 ×1.5。
- **星火与燎原**：连续补对积攒星火，五格全满后可发动“燎原”，本页积分 ×2 并延长 10 秒。
- **三样办法**：询问战友（排除两个记错的选项）、疾行（+10 秒）、参谋（一条史实线索）。
- **判定之后**：补对或补错都会补全句子，并翻出一张“史料附页”，交代这一页的时间、地点与史实出处。
- **最后一页**：合上日记，得到印记、军衔与错题回顾。

## 内容与史实

十二页对应：于都出发、血战湘江、遵义会议、四渡赤水、巧渡金沙江、飞夺泸定桥、翻越夹金山、穿越草地、突破腊子口、吴起镇、会宁会师、星火相传。

- 日记正文为文学化写作，历史骨架、时间、地点、人数与战役结果依据公开党史资料整理。
- 示例中“被迫西迁延安”改为“被迫离开于都”，因为 1934 年 10 月中央红军是从于都出发进行战略转移，并非直接西迁延安；其余保留“普通战士、河南老家、子弹打光、心头一颤”的叙述口吻。
- 每页附一句不超过 30 字的日记式旁注（如“江水红了，浮桥断了。”），用于点出这一页的情绪与画面。
- 史料卡参考中共中央党史和文献研究院等公开资料，仅作学习辅助；页面中的插画、图标均为内联 SVG/CSS 绘制。

## 视觉

- 背景为深色木桌与纸张发黄的笔记本，正文使用行楷（优先“华文行楷”，回退到楷体），尽量做到“潦草但看得清”。
- 被雨水打湿的部分用洇开的水渍表示；补上的字以墨色落回纸面，补对为青绿，补错为朱红。
- 路线图、页码、印章、字条、史料卡都沿用旧纸、墨线、朱砂的视觉语言。

## 技术栈

- HTML5 + CSS3
- 原生 JavaScript（无框架）
- SVG / Canvas / CSS 动画
- Web Audio（音效可开关）
- localStorage（进度、最佳成绩与印记）

## 本地运行

直接双击 `index.html` 即可。若浏览器对本地文件限制较多，可在本目录起一个静态服务：

```bash
python -m http.server 8080
```

然后打开 <http://127.0.0.1:8080/>。

## 发布

这是纯静态站点，可直接部署到 GitHub Pages、Netlify、Vercel、Cloudflare Pages 等平台，入口为 `index.html`，无需后端。

## 浏览器

建议使用较新的 Chrome、Edge、Safari 或 Firefox。移动端已适配安全区和竖屏布局；手机上路线图会作为封面最前面的横向路标出现。
