# 日记版「史料附页配图」接入说明

## 为什么之前看不到图

仓库里跑的是**日记版**（`index.html` + `styles.css` + `diary.css`），它的：

- `game.js` 里 `renderSourceCard()` 只写文字，`HISTORY_CARDS` 没有 `img` 字段；
- `index.html` 的 `#sourceCard` 里没有图片容器；
- 仓库里也没有 `assets/` 目录（`assets/history/yudu-bridge.jpg` 访问是 404）。

所以不是图片加载失败，是这个版本压根没接图。本补丁用**独立脚本**补上，不需要改 `game.js`。

## 三步接入

1. 把本目录下的 `assets/` 整个复制到仓库根目录（和 `index.html` 同级）：

   ```
   仓库根/
   ├─ index.html
   ├─ styles.css
   ├─ diary.css
   ├─ game.js
   ├─ art.js            ← 新增
   └─ assets/           ← 新增
      ├─ route-map-crop.jpg
      └─ history/
         ├─ yudu-bridge.jpg
         ├─ xiangjiang.jpg
         ├─ zunyi.jpg
         ├─ chishui.jpg
         ├─ jinsha-river.jpg
         ├─ luding-bridge.jpg
         ├─ snow-mountain.jpg
         ├─ grassland.jpg
         ├─ mountain-pass.jpg
         ├─ wuqi-cave.jpg
         ├─ huining.jpg
         └─ spark.jpg
   ```

2. 把 `art.js` 放到仓库根目录。

3. 在 `index.html` 末尾，`<script src="game.js"></script>` 的**下一行**加：

   ```html
   <script src="art.js"></script>
   ```

   改完是这样：

   ```html
   <script src="game.js"></script>
   <script src="art.js"></script>
   </body>
   ```

三步之外不用动别的，`game.js` 一行都不用改。

## 它做了什么

- 监听 `#sourceCard` 的显示与 `#sourceCardKicker` 的文字（形如「史料附页 · 第 07 张 / 共 12 张」），据此换图；
- 在附页顶部插入一张「贴在纸上」的照片（米色相框 + 胶带 + 做旧滤镜），和日记本的整体风格一致；
- 图片缺失时整块自动收起，不会出现破图；
- 12 张图分别对应 1—12 站，第 12 张就是「最后一页」。

## 可选：路线图底图

日记版的左侧路线图是手绘 SVG 风格，默认**不**铺照片底图。若想加上，在 `diary.css` 末尾追加：

```css
body.diary .map-frame{
  background:
    linear-gradient(180deg,rgba(241,227,200,.62),rgba(233,216,184,.72)),
    #efe0c2 url("assets/route-map-crop.jpg") 50% 46%/cover no-repeat;
  border-radius:4px;
}
```

## 注意

- **GitHub Pages 没开**：我访问 `https://sikuodesi.github.io/415-/` 返回 404（"There isn't a GitHub Pages site here"）。要在线看效果，需在仓库 `Settings → Pages → Build and deployment` 里选 `Deploy from a branch`，分支 `main`、目录 `/ (root)`，保存后等 1 分钟左右。
- 文件名区分大小写：GitHub Pages 跑在 Linux 上，`Assets/` 和 `assets/` 不是一回事，务必保持小写。
- 若用网页版「Upload files」上传，请**直接拖 `assets` 文件夹**（而不是里面的单个 jpg），否则目录层级会被拍平。
