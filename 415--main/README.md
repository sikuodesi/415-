# 星火长征 · 重走长征路

一个以红军长征十二站为主线的单页互动答题游戏。纯前端实现，无构建步骤、无第三方依赖，克隆后即可运行。

## 玩法

- 12 个长征历史站点，从于都出发到会宁会师
- 单选、排序、匹配三种题型
- 星火与“燎原”连击机制，险关积分加成
- 火眼、疾行、参谋三种锦囊
- 每 3 站一次行军休整：补充补给、恢复锦囊或延时
- 答题后展示一张“史料卡”，含时间、地点、两条史实与资料来源
- 行军手记、错题重练、三种难度
- 桌面与手机自适应

## 技术栈

- HTML5 + CSS3
- 原生 JavaScript（无框架）
- Canvas / SVG / CSS 动画
- Web Audio（音效可开关）
- localStorage（进度与成绩）

## 目录

```
源码/
├─ index.html          页面结构与文案
├─ styles.css          全部样式、响应式与动画
├─ game.js             全部游戏逻辑、题库与史料卡
├─ assets/
│  ├─ opening.jpg      开场图（已去水印、纯红旗版本）
│  └─ history/         史料卡场景图（十二站，每站一张）
├─ README.md
└─ .gitignore
```

## 本地运行

直接双击 `index.html` 即可。若浏览器对本地文件限制较多，可在本目录起一个静态服务：

```bash
python -m http.server 8080
```

然后打开 <http://127.0.0.1:8080/>。

## 发布

这是纯静态站点，可直接部署到 GitHub Pages、Netlify、Vercel、Cloudflare Pages 等平台，入口为 `index.html`，无需后端。

## 素材与史料

- 开场背景图：项目开场素材，已裁掉截图自带水印并处理为纯红旗。
- 史料卡配图：十二站每站一张，位于 `assets/history/`，统一按 3.75:1 取景、裁去原图水印，并由样式表做成旧单色版（`sepia + 降饱和 + 微反差 + 暗角`）。其中遵义会议一图为会址实景照片，其余为 AI 生成的学习辅助画面。
- 路线底图：`assets/route-map.jpg`，由长征路线示意图反相着色而来（深底金线、保留红色行军路线），铺在左侧「征途十二站」面板的底图上，上面叠加本作的星站与行进线。
- 替换与扩充：把同名文件覆盖到 `assets/history/` 即可，无需改代码；也可给 `game.js` 中对应的 `HISTORY_CARDS` 项写 `img: 'assets/xxx.jpg'`。不写 `img` 的卡片自动回落到内置的 SVG 木刻插图。
- 史料卡与史实：据中共中央党史和文献研究院等公开资料整理，作为学习辅助。
- 页面中的插画、图标均为内联 SVG/CSS 绘制；`assets/history/` 中的场景图除遵义会址外均为 AI 生成画面，不是历史照片，请勿作为史料引用。
